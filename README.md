# Elecrow Home Assistant Panel Enclosure

A simple 3D-printable enclosure for the **Elecrow 10.1" ESP32-P4 Home Assistant Control Panel**.

The panel is designed to display your existing Home Assistant dashboard directly from the Home Assistant server, but it is also available without an enclosure. These files provide a simple printable case for it.

## Files

- TopCover^HAPanel.STL — front part of the enclosure
- BottomCover^HAPanel prot.STL — rear part of the enclosure

Feel free to print, modify, or adapt the design for your own setup.

Feedback and improvements are welcome.
